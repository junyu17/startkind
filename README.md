# StartKind

StartKind is an iOS-first execution assistant for adults with ADHD-style executive function challenges. It is not a task manager first. It is a start, restart, and co-start system that turns overwhelm into one small action the user can begin now.

Default language: US English.
Optional language: Simplified Chinese.

## Product Positioning

Primary tagline:

> One kind step to start.

App subtitle:

> ADHD Execution Assistant

Chinese subtitle:

> 成人 ADHD 轻启动助手

The app must avoid shame-based productivity patterns. It does not punish missed tasks, show hostile overdue states, or push long lists by default. The first screen should help a user start one action in 5 to 15 minutes.

## Platform Strategy

Launch iOS first and validate market demand before starting Android development. Android remains a future expansion path, but it must not block the first iOS App Store release.

## Non-Negotiable Development Rule

Every code change must be self-reviewed and tested before delivery. A developer or AI agent may not report completion after only writing code. They must verify that the change builds, passes relevant tests, and matches the original requirement.
